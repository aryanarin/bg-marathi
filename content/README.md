# Content

Scripture content, one JSON file per chapter: `chapter-01.json` … `chapter-18.json`.

**This directory is currently empty.** Content is supplied by the project owner;
none of it is generated. See [`../docs/content-import.md`](../docs/content-import.md)
for the file format, the field reference and the validation rules.

## Workflow

```bash
cd ../web
npm run content:validate          # all chapters
npm run content:validate -- 01    # one chapter
```

Validation is read-only and never touches the database. It must pass before
import.

## Naming

The filename must agree with `chapter_number` inside the file — `chapter-01.json`
must contain `"chapter_number": 1`. The validator enforces this, because a
mismatch would silently write to the wrong chapter.

## A note on the two authored fields

`easy_explanation` and `example` are written by the administrator, not imported
from the source edition and never generated by the application. They may be
empty strings at import time and filled in later through the admin interface.
